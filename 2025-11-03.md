# Drive Base Configuration/Tuning Workshop

## Summary

In this session we covered:
- Configuring the 2025 swerve drive base with Phoenix Tuner X
- Setup of the AdvantageKit TalonFX Swerve Template
- Reviewed the TalonFX Swerve Template command code
- Discussion of input deadzones and shaping options

## Configuring and setup of the Drive Base

I unzipped the [TalonFX Swerve Template download](https://github.com/Mechanical-Advantage/AdvantageKit/releases) into a new project folder and initiated a [git repository](https://github.com/frc538/2025-swerve-template-workshop).

We followed the [TalonFX Swerve Template instructions](https://docs.advantagekit.org/getting-started/template-projects/talonfx-swerve-template).  

The 2025 swerve drive base is built using a pre-selected configuration of CTRE devices that is compatible with [Phoenix Tuner X swerve project generator](https://v6.docs.ctr-electronics.com/en/latest/docs/tuner/tuner-swerve/index.html).  The robot was placed on wooden blocks to allow the wheels to move freely and we proceeded with updating firmware on some of the devices and generating a tuner configuration.

The project is left with voltage control for turn and drive motors.  I believe we have a Phoenix Pro subscription though, so some further investigation could be done to determine if we can or should switch to Torque-current control.

We skipped step 1 of the Feedforward Characterization section.  This step is something we will want to do with the 2026 robot.  We also skipped the Slip Current measurement.  This would be best to execute with the robot on a carpet which we did not have available.

The template code includes a DriveCommands.java file which provides a couple methods to control the drive subsystem.  We did a review of the methods that drive from joystick, and drive while holding an angle.  The drive code uses a dead-zone and quadratic input shaping for turn commands.  We discussed what a dead-zone is, and a couple options for input shaping including quadratic, cubic, or drive speed modes.
