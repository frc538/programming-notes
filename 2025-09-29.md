# Tools Introduction Session

## Summary

In this session we covered:
- Driver Station
- Rev Hardware Client
- Phoenix Tuner X
- Real-time telemetry (Labview, Shuffleboard, Elastic)
- AdvantageScope
- Path Planner
- We examined last years robot, identifying components of interest and discussing their function

## Tools

- [FRC Game Tools](https://www.ni.com/en/support/downloads/drivers/download.frc-game-tools.html) (Version 2025 Patch 1) - note that this is a Windows-only piece of software (Windows 10 or Windows 11)
  - Driver Station:
    - Used to interface with the robot, check some telemetry states
    - Used to configure controllers
    - Check the team number is correct
- [Rev Hardware Client](https://docs.revrobotics.com/rev-hardware-client)
  - Used to update Rev hardware firmware versions
  - Used to do simple tests, running, or simple closed loop control on a sparkmax
- [Phoenix Tuner X](https://v6.docs.ctr-electronics.com/en/stable/docs/tuner/index.html)
  - Used to update CTRE device firmware
  - Generates the CTRE swerve drive configuration (Used in 2025 robot, and requires specific CTRE hardware)
  - Available from the Windows store
- Real-time telemetry
  - Driver Station (NI Tools) provides a very simplistic telemetry interface
  - Shuffleboard is available as a WPILIB component, but is not actively developed
  - [Elastic](https://frcdocs.wpi.edu/en/latest/docs/software/dashboards/elastic.html) provides a simple dashboard that is actively developed.
- AdvantageScope
  - [AdvantageScope](https://docs.advantagescope.org/) is a diagnostic tool that is used to view real-time or recorded telemetry with a variety of different data visualization options.
  - This will be used often to debug the behavior of the robot.
  - AdvantageScope is optimized for use with AdvantageKit which is a robot logging framework that was used in the 2025 season and will likely be at least partially used in 2026.
- Path Planner
  - [Path Planner](https://pathplanner.dev/home.html) is an application that makes it easy to develop automatic paths to support autonomous operation.
  - Paths are generated on a graphic interface and imported into the code as a series of waypoints.
