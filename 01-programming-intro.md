## Basecamp

Basecamp is used for chatting with the whole robotics team, and is for mentors and students only.
The intent is that this is a centralized place for planning and coordinating without annoying parents in the main chat.

Tasks can be assigned and status provided.
Documents will be shared on basecamp.

The programming team creates a software design google document each year, linked from Basecamp.
This document captures the code design, interface notes, command details, user notes, and anything that is relevant to the construction and function of software.

## GroupMe

GroupMe is used for active communication with the entire team.
Limit messaging in the main chat since that involves all students, mentors, and parents (70+ people).

Mark your availability for individual events when you know it.
If you can't make it to a meeting, marking yourself as unable to make it is sufficient.

## Software Creation

We program robots in the Java programming language.
The offseason lessons will be focused on learning how to program robots.
Workshops will be held in some cases to develop skills and capability as a team (learning for mentors too!).

A Code HS course has been established for non-robot Java lessons: 
https://codehs.com/go/78A7D
It is not required that students participate in the Code HS course.
It is available as a good resource for general programming knowledge and skills.

We will establish a repository to hold the code for the new game when it is released.
The main branch will contain the official code that is tested and ready to use.
We will execute peer reviews of every change (at least 1 mentor must approve).

To get code into the main branch:
- Create a feature branch to implement a single feature
- Implement the change
- Test the change to ensure it works as intended
- Create a merge request into the main branch
- Mentors and other students will review the code and provide comments or findings, providing approval once findings are resolved.
- Correct the findings
- Merge the change when all reviewers have approved and findings are resolved.

## Software and Accounts

GitHub is the place where the programming team maintains code and programming notes using git.
If you do not already have an account, you should create one at [GitHub](https://www.github.com).
Once you have an account, you can be added to the team.

If you wish to install software on your computer, these are the components suggested:
- [GitHub Desktop](https://desktop.github.com) (for users not already experienced with the `git` command-line tool)
- [First Driver Station](https://github.com/wpilibsuite/FirstDriverStation-Public/releases/tag/v2027.0.0-alpha-7) (Version 2027.0.0 Alpha 7)
- [WPILib](https://github.com/wpilibsuite/allwpilib/releases/tag/v2027.0.0-alpha-7) (Version 2027.0.0 Alpha 7)

In addition, we reviewed two useful sources of information:
- [WPILib Documentation](https://docs.wpilib.org/en/stable/index.html). A good first-stop if you are learning more about a topic in robot programming or control systems.
- [Chief Delphi](https://www.chiefdelphi.com). **The** primary community forum for FRC teams. Great for finding answers to specific questions.
