# XRP Build and Test Session

## Summary

The team built XRP robots during this session, reviewed the top level Robot and RobotContainer code, tested and corrected the controls for their robots.

## XRP Build

The team followed the [XRP build instructions](https://frcdocs.wpi.edu/en/stable/docs/xrp-robot/hardware-and-imaging.html) and imaged each robot for use with WPILIB.

## XRP Programming

Once the robots were built and imaged, each student created an XRP program to control it following the [Programming the XRP](https://frcdocs.wpi.edu/en/stable/docs/xrp-robot/programming-xrp.html) instructions.

Using the available playstation-style controllers, we noted the control axes did not map as expected.

Using the [FRC Driver Station USB Devices Tab](https://frcdocs.wpi.edu/en/stable/docs/software/driverstation/driver-station.html#usb-devices-tab) or the relevant [Glass simulation interface](https://frcdocs.wpi.edu/en/stable/docs/software/dashboards/glass/index.html) USB information, we identified desirable axes on the controller for the axis control, and modified the code to utilize those indices.
