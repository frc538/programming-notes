## Basecamp

Basecamp is used for chatting with the whole robotics team, and is for mentors and students only.  The intent is that this is a centralized place for planning and coordinating without annoying parents in the main chat.

Basecamp uses a card-based interface.  Tasks can be assigned and status provided.  Documents may be shared on basecamp.

The programming team has a "Software notes and ideas" document with design information from the 2025 season.  The programming team will develop a similar document for the 2026 season that captures the code design, interface notes, command details, and user notes.

## GitHub

GitHub is the place where the programming team maintains code and programming notes using git.

We will establish a repository for the 2026 game when the game is released.  The main branch will contain the official code that is tested and ready to use.

To get code into the main branch:
- Create a feature branch to implement a single feature
- Implement the change
- Test the change to ensure it works as intended
- Create a merge request into the main branch
- Mentors and other students will review the code and provide comments or findings, providing approval once findings are resolved.
- Correct the findings
- Merge the change when all reviewers have approved and findings are resolved.
